# Humans 1.4.6

One-handed tools and machetes now use a separate hand attachment rotation: a 180-degree local-X correction reverses the inward-facing orientation reported in the screenshots. This applies to the pipe, lug wrench, wrench, police baton, meat tenderizer, hammer, all three machetes and legacy crowbars. The three baseball bat variants retain their existing grip rotation. The hand anchor is unchanged.

The correction applies when a weapon is attached; replace/reload existing NPCs to see it. Install the updated mod on server and clients and restart.

Built and signed; resource checks passed. This rotation is based on the supplied screenshots and has not been visually verified in-game across idle and attack animations.
