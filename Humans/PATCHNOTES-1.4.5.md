# Humans 1.4.5

The Human fist hit that lowers a living player's shock below the unconscious threshold now leaves two active bleeding cuts. Existing cuts count toward the two; this does not add two more cuts on every punch or remove additional existing wounds. Blocked hits, invulnerable targets, fatal hits and hits on players already below the threshold do not trigger this addition.

Fists retain 20 health and 20 shock damage before armor. Four rapid unprotected punches from full health/shock leave 20 health and trigger knockout plus two cuts. Shock recovery and armor can alter the number of punches required. Weapons retain native damage.

Built and signed; resource validation passed. Native bleeding API and selection names checked against local DayZ sources. This addition has not been verified in a live knockout encounter.
